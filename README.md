# Vibed

Premium job board for Vibe Coders, AI Engineers, and AI-Assisted Developers.

## Features

- **Dynamic Search**: Filter jobs by role, company, description, and location
- **Tech Stack Filters**: Quick filter by Cursor, Windsurf, Claude Code, Aider, or APIs
- **Expandable Job Listings**: Click any job to see detailed descriptions
- **Post a Job**: Submit new job listings with validation
- **European Focus**: All jobs based in European tech hubs (Amsterdam, Berlin, London, Paris, etc.)
- **Live Updates**: New jobs appear instantly in the stream
- **Dynamic Background**: Scroll-responsive gradient effect

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Geist Sans font

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
